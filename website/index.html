Questions

Straight answers

Is Meloqis Music really free?
Yes — completely free, with no ads and no subscriptions. It's an open-source project.
How do updates work?
Meloqis has in-app updates. When a new release is published, open the app, tap update, and the latest version downloads and installs itself.
Is it safe to install?
The app is open source and the code is public on GitHub. You install the APK directly, so you can review and build it yourself.
Where is my data stored?
Your library and preferences stay on your device. Meloqis keeps things private and local.
Which Android versions are supported?
Android 8.0 (Oreo) and newer.
