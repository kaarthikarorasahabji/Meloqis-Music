Privacy, plainly.

Meloqis 0.1.9 remains a development preview. Anonymous insights can be disabled at any time in Settings → Privacy.

On your device

Meloqis may store settings, listening history, playlists, cache, downloads, and integration tokens locally. Android cloud backup is disabled for the Meloqis package.

Optional permissions

The Now Capsule asks for “Display over other apps” only when enabled. It displays and controls Meloqis playback; it does not read notifications, use accessibility services, or inspect other apps. Microphone, notifications, audio/media, and Bluetooth permissions are used only for the features that need them.

Anonymous app insights

Meloqis can send first-open and daily activity signals, app and Android versions, update outcomes, crash class names, and Media3 playback error codes to an Axenora-controlled Cloudflare Worker and D1 database. It never sends IMEI, phone number, advertising ID, Android ID, account data, song titles, artists, playlists or listening history for analytics.

The app creates a random installation UUID and the server stores only its SHA-256 hash. Detailed events are removed after 90 days; inactive installation activity and download counts are removed after 400 days. Cloudflare processes normal connection information to deliver and secure the service. Meloqis does not store raw IP addresses in the analytics dataset; for abuse prevention only, it keeps a non-reversible keyed hash of the connection address and time window for no more than 48 hours.

Anonymous insights are enabled by default in Meloqis 0.1.9. Turn off Share anonymous app insights in Settings → Privacy to stop future uploads and clear events that have not yet been sent.

Network integrations

If you choose a network feature, the selected provider receives the information required for that request and normal network data such as an IP address. Only Axenora-owned or properly authorized services may ship in a public Meloqis release.

Contact status

A dedicated privacy contact and deletion process will be published before launch. Official website: axenoraai.in.
